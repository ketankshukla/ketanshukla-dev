# Ketan Shukla — Developer Portfolio

A polished, dark-themed developer portfolio built with **Next.js 16**, **React 19**, and **Tailwind CSS v4**. It showcases a five-project series on the **Model Context Protocol (MCP)**, from first-party servers to agent loops, approval gates, multi-agent crews, and cost-aware sampling hosts.

## Live preview

- **Production:** https://ketanshukla-dev.vercel.app
- **Local:** `npm run dev` then open http://localhost:3000

## What’s inside

- Hero with profile photo, value proposition, and key stats
- Five featured MCP projects with live URLs, GitHub links, and API endpoints
- About section + skills grid
- Contact / footer with GitHub, personal site, and email

## Stack

- Next.js 16.3.2 (App Router, Turbopack)
- React 19.2.8
- TypeScript 5
- Tailwind CSS v4
- lucide-react
- @vercel/analytics

## Running it

```bash
npm install
npm run dev
```

## Deploy

This project is set up for [Vercel](https://vercel.com). Push to `main` and Vercel will build and deploy automatically.
